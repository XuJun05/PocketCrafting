# PocketCrafting

A Minecraft Mod for BTA7.3 (MinecraftBeta1.7.3)

## Features

This mod adds a workbench that can be used without placing it down.

    PocketWorkbench

## Supported Languages

    🇺🇸 English
    🇯🇵 日本語
    🇨🇳 简体中文


## Dependencies


    HalpLibe
